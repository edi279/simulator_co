# 직장생활 시뮬레이터 (Workplace Simulator)

직장 내 상호작용과 관계를 시뮬레이션하는 웹 애플리케이션입니다.

## 시작하기

1. 저장소를 클론합니다.
2. 의존성을 설치합니다.
   ```bash
   npm install
   ```
3. **중요**: 시나리오 파일을 설정합니다.
   `src/logic/scenarios.demo.ts` 파일을 복사하여 `src/logic/scenarios.ts`로 이름을 변경하세요.
   ```bash
   cp src/logic/scenarios.demo.ts src/logic/scenarios.ts
   ```
4. 개발 서버를 실행합니다.
   ```bash
   npm run dev
   ```

## 기술 스택
- React, Vite, TypeScript
- Tailwind CSS
